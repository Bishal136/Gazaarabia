## 2. Server-Side Optimization (Nginx & Brotli)

We have created an automated production Nginx configuration in `deploy/nginx-gazaarabia.conf` and real IP mapping in `deploy/cloudflare-ips.conf`.

### To apply this configuration on your VPS:
Log into your VPS via terminal and execute:
```bash
sudo /var/www/Gazaarabia/deploy/install-nginx-tuning.sh
```

### What this automated script does:
1. **Restores Visitor Real IPs**: Sets up `/etc/nginx/conf.d/cloudflare-ips.conf` so visitor IPs from Bangladesh are preserved for analytics, security, and logs.
2. **Direct Disk Serving**: Configures Nginx to serve `/_next/static/*`, `/uploads/*`, and `/images/*` directly from disk with `sendfile`, bypassing Node.js completely.
3. **HTTP/2 & TLS 1.3 Caching**: Enables 50MB shared SSL session cache (`ssl_session_cache shared:SSL:50m`) and 4KB SSL buffer size (`ssl_buffer_size 4k`) to eliminate TTFB packet stalls.
4. **Upstream Keepalive Pool**: Keeps 64 warm TCP connections open between Nginx and Node.js/PM2 cluster, eliminating socket teardown delays on dynamic requests.
5. **Precompressed Assets**: Serves pre-compressed `.gz` and `.br` files generated by `scripts/precompress-assets.mjs`.

## 3. Step-by-Step Cloudflare CDN Integration

### Step 1: Add Domain to Cloudflare
1. Log into your [Cloudflare Dashboard](https://dash.cloudflare.com/).
2. Click **+ Add a Site** and enter `gazaarabia.com`.
3. Select the **Free** plan (or Pro if desired).
4. Cloudflare will scan your existing DNS records.

### Step 2: Configure DNS Records (Orange-Cloud Proxied)
Ensure your primary records have the **Orange Cloud (Proxied)** enabled:
- **Type**: `A` | **Name**: `@` (or `gazaarabia.com`) | **IPv4 address**: `87.106.110.91` | **Proxy status**: `Proxied (Orange Cloud)`
- **Type**: `CNAME` | **Name**: `www` | **Target**: `gazaarabia.com` | **Proxy status**: `Proxied (Orange Cloud)`
- **Type**: `A` (if using custom webhook or direct SSH subdomains): Keep unproxied / DNS only if needed.

Update your domain registrar nameservers to Cloudflare's assigned nameservers (e.g., `*.ns.cloudflare.com`).

### Step 3: Configure SSL/TLS Mode (CRITICAL)
In the Cloudflare dashboard:
1. Navigate to **SSL/TLS** -> **Overview**.
2. Select **Full (Strict)**.
   > **Note**: Do NOT select "Flexible". Flexible will cause an infinite redirect loop because Nginx redirects HTTP to HTTPS. Since your VPS already has an active Let's Encrypt certificate, **Full (Strict)** ensures end-to-end encryption.
3. Under **SSL/TLS** -> **Edge Certificates**:
   - Turn **Always Use HTTPS** -> **ON**.
   - Turn **Minimum TLS Version** -> **TLS 1.2**.
   - Turn **Opportunistic Encryption** -> **ON**.
   - Turn **TLS 1.3** -> **ON**.
   - Turn **Automatic HTTPS Rewrites** -> **ON**.

### Step 4: Configure Cloudflare Cache Rules
Navigate to **Caching** -> **Cache Rules** -> Click **Create Rule**:

#### Rule 1: Static Assets Aggressive Edge Cache
- **Rule Name**: `Cache Gazaarabia Static Assets`
- **When incoming requests match**:
  - Expression: `(http.request.uri.path starts_with "/_next/static/") or (http.request.uri.path starts_with "/uploads/") or (http.request.uri.path starts_with "/images/") or (http.request.uri.path.extension in {"webp" "avif" "png" "jpg" "jpeg" "svg" "ico" "woff2" "woff" "css" "js"})`
- **Cache Eligibility**: **Eligible for cache**
- **Edge TTL**: Use Cache-Control header if present, or override with **1 month** (for immutable Next.js chunks, set **1 year**).
- **Browser TTL**: Respect existing headers.

#### Rule 2: Dynamic & Authenticated Bypass
- **Rule Name**: `Bypass Auth and Admin Portals`
- **When incoming requests match**:
  - Expression: `(http.request.uri.path starts_with "/admin") or (http.request.uri.path starts_with "/seller") or (http.request.uri.path starts_with "/affiliate") or (http.request.uri.path starts_with "/api/auth") or (http.request.uri.path starts_with "/cart") or (http.request.uri.path starts_with "/checkout") or (http.request.uri.path starts_with "/account")`
- **Cache Eligibility**: **Bypass cache**

### Step 5: Speed & Optimization Settings
In Cloudflare dashboard, navigate to **Speed** -> **Optimization**:
1. **Brotli**: Turn **ON** (compresses text assets 20% smaller than Gzip).
2. **Early Hints**: Turn **ON** (transmits `103 Early Hints` link headers so browsers preload CSS/JS before HTML finishes rendering).
3. **HTTP/2**: Turn **ON**.
4. **HTTP/3 (with QUIC)**: Turn **ON** (enables 0-RTT connection resumption and resilience against mobile packet loss in South Asia).
5. **0-RTT Connection Resumption**: Turn **ON**.
